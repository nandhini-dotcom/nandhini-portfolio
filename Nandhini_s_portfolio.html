Machine learning · Cybersecurity

AI-based malicious website detection system

PythonFlaskScikit-learnHTML/CSS
The problem

Malicious websites are built to look convincing. Nandhini wanted to know if machine learning could flag risky URLs before someone clicks through.

Her approach
  • Compared five algorithms: Logistic Regression, Decision Tree, Random Forest, SVM, Gradient Boosting
  • Evaluated each on accuracy, precision, recall, F1-score, and AUC-ROC
  • Built a Flask interface for real-time URL analysis
What it showed

No single algorithm was automatically "best" — trade-offs mattered. That evaluation-first habit now shapes how she approaches any ML problem.
